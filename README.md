# Fortune Cookie for the Liquidated Trader

One fortune cookie line for a crypto trader who just got liquidated —
oracular on the front, honest on the back.

> You will find great wealth where you least expect it: in the job you quit to trade crypto.

`main.ts` writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(18 words, 90 characters, one line, UTF-8). Node 22 standard library only;
no network, no files read, no randomness — the same bytes every run.
